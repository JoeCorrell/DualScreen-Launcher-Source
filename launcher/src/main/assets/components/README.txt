These component archives were captured from the installed WEMU `Games`
container on the AYN Thor on 2026-08-28. They are immutable installation
inputs for the predefined launcher container, not user-selectable components.

Each archive contains the exact profile.json and installed file tree used by
that container. ComponentProvisioner verifies the embedded profile identifier
before adopting an archive.

# Link's Awakening development profile

This profile enables base-game/update import and ordinary game launch using the
existing Eden backend. It does **not** claim a completed touchscreen companion.
The manifest installs no patches and does not modify save data.

The target under investigation is title `01006BB00C6F0000`, **base version 1.0.0**,
main build `AE16F71E002AF8CB059A9A74C4D90F34BA984892`.
No update file is required for this target. This matches the user's existing
Stable 60fps v2 patch build; matching builds alone is not a gameplay stability test.
Historical 1.1.0 research is reference-only and must not be applied to the base
executable without independent verification. Existing installed updates are not
automatically removed or disabled by this development profile.
See `../../eden-upstream/docs/LinksAwakeningDualScreen.md` for native evidence,
remaining validation and local extraction tools.
